Q1.) What is 'software'?
Software is a set of instructions or commands created to tell a computerised system, device or any application what to do and how to follow through with such commands. More specifically, software details to a system each specific step it must take to fufill a request, as in: 
  - What to do...
  - How to do it...
  - When to do it...
  - etc....
Software also adds much more interactivity to a system allowing users to use a system in a more meaninful way, making it easier to access a devices full capabilities.

Personally, applications like VSCode, Github, Git, VMWare, etc... are all ssoftware applications work well with very little issue from my experience. 
- Successes: VSCode allows me to place my code in a secure, featurefull enviroment that easily handles integration while also being able to seemlessly interact with other applications such as Git, which helps save and document changes to my code.
VMWare also provides me with an easy way to create virtual instances for testing applications/security measures and helps me understand system configutations much easier. 
  
- Failures: VSCode falls short when it comes to it's interface. It is sometimes overbearing for the user from many of it's tools and popups when coding. 
Vmware, for example, is very hardware dependant and the perfomance of it's virtual instances vary depending on the machine you use. Additionally, it is also prone to crashing, long loading times and general syncing errors. 

What the developers might have done differently? 
VSCode developers could implement a more simplified coding mode which hides uncessary features and toolbars, making it easier to code. For VMWare, the developers could use more resource-throttling features to help create virtual instances more based on the current hardware andhelp optimise it to prevent crashing and long wait times. 


On the otherhand, I occasionally have issues with software like Blackboard and Word. 
- Successes: World is a great application for writing and saving documents with many tools that allow me to customise my writing style. As well as that, Blackboard also acts as a central hub for all college work, such as taskts to go, grades, and upcoming work-related events. 

- Failures: As for Word, it can feel really slow and lags quite often when writing long complex documents. It also has many issues with implementing non-text related items such as images or videos. 
Blackboard is often times overcluttered with options and features that most users don't interact it, overbearing the interface. It is also suffers from too many nested menus which can confuse users.

What the developers might have done differently?
Word developers could create a better system for their image and video processing, seperate from the normal text input, allowing them to work seemlessly while still on the same document. 
For Blackboard, developers could reduce the amount of nested menues and made features more accessible to users, simplifying it's design.


Q2.) What does 'engineering' add to software? 
Engineering adds a core structure to pre-established software. The engineering aspect of software turns a simple piece of code or script into a much more reliable and permanent system, such as being able to handle more scalability to add or remove features in the future, in general has longer run times and will be used more than typical, not-thought out code and has much more failure handling through automated testing and security features.
